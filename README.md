# Wiki de INFERNMC Network

Sitio estático en HTML, CSS y JavaScript preparado para publicarse gratis con GitHub Pages.

## Archivos
- `index.html`: contenido de la wiki.
- `styles.css`: diseño responsive oscuro con detalles rojos.
- `script.js`: copiar IP, menú móvil y navegación activa.

## Publicar con GitHub Pages
1. Inicia sesión en https://github.com/
2. Pulsa **New repository**.
3. Ponle un nombre, por ejemplo `infernmc-wiki`, y selecciona **Public**.
4. Crea el repositorio.
5. Pulsa **Add file → Upload files** y sube `index.html`, `styles.css`, `script.js` y `README.md` (o arrastra los cuatro).
6. Pulsa **Commit changes**.
7. Ve a **Settings → Pages**.
8. En **Build and deployment**, selecciona **Deploy from a branch**.
9. Selecciona la rama `main` y la carpeta `/ (root)`. Pulsa **Save**.
10. Espera unos minutos y GitHub mostrará la URL de la página en esa misma sección.

## Antes de publicarla
- Confirma que `infernmc.nyxelis.tech` sea la IP correcta.
- Añade el enlace real de Discord en el botón de comunidad si quieres que lleve a tu servidor.
- Los modos de juego y rangos incluidos están marcados como ejemplos o por confirmar. Edítalos para que coincidan con los servicios reales de INFERNMC.
- Puedes cambiar colores y textos en `styles.css` e `index.html`.

## Dominio personalizado
Si tienes un dominio propio, puedes configurarlo en **Settings → Pages → Custom domain**. No es necesario para publicar con la dirección gratuita `github.io`.
